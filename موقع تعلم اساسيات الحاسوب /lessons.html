🏠 الرئيسية 📘 الدروس 📞 تواصل معنا

HTML

💻 ما هي HTML؟

HTML هي لغة تُستخدم لإنشاء هيكل صفحات الويب، مثل العناوين، الفقرات، الصور، والروابط.

🧱 أول صفحة HTML

أي صفحة HTML تبدأ بالوسم <html> وتنتهي بالوسم </html>، وتحتوي على <head> و <body>.

CSS

🎨 ما هي CSS؟

CSS تُستخدم لتنسيق صفحات HTML، مثل تغيير الألوان، الخطوط، وحجم العناصر، وترتيبها.

🖌️ قواعد CSS أساسية

يمكننا استخدام المحددات (Selectors) لتطبيق الخصائص (Properties) على العناصر في الصفحة.

JavaScript

⚡ ما هي JavaScript؟

JavaScript لغة برمجة لإضافة التفاعل إلى صفحات الويب، مثل النوافذ المنبثقة، التحقق من النماذج، وتحريك العناصر.

📝 مثال بسيط

<script>alert("مرحبا بالعالم!");</script> يظهر رسالة منبثقة عند فتح الصفحة.
